# bush_sniper
## 2D Multiplayer Game with a TopDown View.

In this Project i tried out some things for a simple 2D multiplayer shooter with topdown view, in a Battle Royale Style:

-Random Map Generation
-Serverless Multiplayer
-Player Movement, Shooting Mechanics and Audio
